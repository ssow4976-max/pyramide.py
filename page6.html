Git & GitHub

Pour le rendu final, soumets ton projet sur GitHub avec au moins 8 commits répartis sur deux semaines. Le dépôt doit être public et le lien GitHub Pages fonctionnel.

  • Nom du dépôt NOM-Prenom-AfriConnectSummit
  • CommitsMinimum 8 commits clairs et en français
  • DéploiementGitHub Pages activé
  • READMEPrésente le projet, les technologies et le lien
Toute similarité de code entre étudiants peut entraîner un 0/20. Prépare-toi à expliquer chaque fonction JavaScript et chaque propriété CSS avancée.
