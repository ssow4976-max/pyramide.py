# AfriConnect Summit 2026

Projet de site vitrine pour l'examen AfriConnect Summit 2026.

## Auteur
- Samba Sow

## Description
Site événementiel fictif présentant un sommet panafricain pour développeurs, entrepreneurs et investisseurs. Le projet inclut plusieurs pages statiques, un menu de navigation cohérent et des fonctionnalités JavaScript accessibles.

## Pages
- `index.html` — page d'accueil
- `programme.html` — programme complet
- `intervenants.html` — intervenants avec filtrage dynamique
- `contact.html` — formulaire de contact avec validation
- `page6.html` — ressources autorisées et consignes GitHub
- `resume.html` — résumé du projet avec nom et dépôt GitHub

## Fonctionnalités
- Navigation cohérente entre toutes les pages
- Mode sombre avec stockage local
- Validation de formulaire accessible
- Filtrage dynamique des intervenants sans rechargement
- Bouton retour en haut après 300px
- Année dynamique dans le footer
